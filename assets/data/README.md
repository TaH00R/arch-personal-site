# Site data

Edit the files in this directory instead of editing `terminal.js` or `desktop.js`.

- `site.js` — machine/person identity
- `projects.js` — projects
- `skills.js` — skills
- `socials.js` — social links
- `about.js` — about text
- `poetry.js` — poems
- `stats.js` — Steam / Spotify / GitHub stats
- `blogs.js` — blog route slugs
- `fortunes.js` — `fortune` command output
- `music.js` — music player metadata

The UI, terminal and virtual filesystem all read from these files.
